ABOUT

六個學校系統，
一個 App 整理好。

課表在校務系統、作業在 M 園區、信件在 NUMail、討論室在圖書館……NIU-Life 用你原本的學校帳號一次登入，把常用的功能放在同一個地方，介面為手機重新設計。

  • 校務系統
  • M 園區
  • 校園信箱
  • 圖書館
  • 活動報名
  • 郵務查詢

FEATURES

NIU-Life 能做什麼

  1. 01今天的課，一眼就知道

    • 首頁顯示上課中與下一堂，含時間與教室
    • 點課程直接開 M 園區
    • 主畫面小工具、上課前提醒

  2. 02整週課表，一次看完

    • 星期與日期、今天整欄標出
    • 紅線標出現在時間
    • 週六日有課也放得下

  3. 03校園信箱，不用再開網頁

    • 收信、寫信、回覆與轉寄，支援附件
    • 登入驗證碼自動辨識
    • 信件匣、搜尋、搬移與刪除

  4. 04請假，進度看得清楚

    • 在 App 裡申請並上傳證明
    • 簽核到哪一關、誰簽的都看得到
    • 被退回時，原因放在最上面

  5. 05圖書館，入館不用找

    • 入館 QR Code 與借書條碼
    • 研究小間、討論室預約
    • 自動調亮螢幕方便掃描

  6. 06M 園區與快速點名

    • 公告、教材、作業、成績與出席
    • 掃描老師的 QR Code 點名
    • 作業截止前提醒

PRIVACY

你的帳號，
只用來連學校。

  • NIU-Life 沒有自己的伺服器，校務資料只在你的手機和學校之間傳遞
  • 帳號密碼存在手機的安全儲存，不會送到開發者手上
  • 請假、報名、寄信都由你按下按鈕才送出，不會自動重送
  • 程式碼以 MIT 授權公開，任何人都可以檢查

FAQ

常見問題

NIU-Life 是學校官方的 App 嗎？

不是。NIU-Life 由個人開發，與國立宜蘭大學沒有隸屬、合作或授權關係。校務資料、點名與報名結果請以學校官方系統為準。

要怎麼登入？

用你原本的國立宜蘭大學校務帳號登入就好，不需要另外註冊。App 會用同一組帳號連到 M 園區、校園信箱與圖書館。

我的帳號密碼安全嗎？

帳號密碼只存在你手機的安全儲存，只用來連線學校系統，不會傳到開發者的伺服器。登出時會一併清除。詳細內容請看隱私權政策。

為什麼有些功能偶爾會讀不到？

App 直接連學校的系統，學校系統維護、忙碌或要求重新驗證時，對應的功能就會暫時無法使用。課表、成績等會先顯示上次的資料，稍後再試即可。

iOS 版和 Android 版有什麼不同？

兩個版本功能大致相同，各自依平台設計：iOS 版有即時動態與鎖定畫面小工具，Android 版有 App 捷徑與上課中通知。兩邊分別由不同開發者維護。

遇到問題要找誰？

Android 版請寄信到 hi@windless.me，或到 GitHub 回報；iOS 版請到 iOS 專案的 GitHub 回報。請不要附上密碼或仍可使用的 QR Code。
